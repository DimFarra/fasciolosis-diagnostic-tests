# Bayesian latent class analysis of fasciolosis diagnostic tests

Supplementary code for manuscript 1905735.

This package estimates the sensitivity and specificity of ELISA, coprology and liver inspection in sheep and goats sampled in the Lake Chad region.

## Data and models

The herd analysis includes 217 animals with paired ELISA and coprology results from three sampled populations: Arab (76), Goran (23) and Fulani (118). The slaughterhouse analysis includes 109 sheep and goats with complete results for all three tests. Aggregate cross-classifications are defined in `data_counts.R`.

Conditional-independence models form the primary analyses. Alternative prior distributions and conditional-dependence models are evaluated in sensitivity analyses. The reported results comprise 24 model specifications: 11 herd and 13 slaughterhouse fits.

The primary herd model is fitted first. Posterior means and variances for ELISA and coprology sensitivity and specificity are moment-matched to Beta distributions for the slaughterhouse baseline. Latent prevalence is specified separately, and baseline liver-inspection sensitivity and specificity have Beta(1,1) priors. Test-prior sensitivity scenarios replace the transferred priors.

## Requirements

- R 4.4 or later
- JAGS 4.3
- R packages `rjags` and `coda`
- R package `PriorGen` for the optional prior-construction check

## Reproduction

Run from the package root:

```sh
Rscript scripts/run_models.R
Rscript scripts/run_models.R --include-dependence
Rscript scripts/check_repository.R
Rscript scripts/validate_models.R
Rscript scripts/prepare_outputs.R
Rscript scripts/plot_diagnostics.R
Rscript scripts/reconstruct_priors.R
```

The first command fits the conditional-independence models. The second additionally includes conditional-dependence sensitivity analyses. The remaining commands check the results and generate reporting outputs, diagnostic plots and prior summaries.

Four fixed-seed chains use 5,000 adaptation iterations, 10,000 burn-in iterations and thinning by five. Sampling continues in blocks until all monitored parameters meet PSRF ≤1.01 and effective sample size ≥1,500, subject to the configured maximum. Intervals are equal-tailed 95% credible intervals, based on the 2.5th and 97.5th percentiles.

## Files

| Location | Contents |
|---|---|
| `data_counts.R` | Aggregate diagnostic cross-classifications and baseline prior constants |
| `model_helpers.R` | Likelihoods, covariance bounds and probability checks |
| `R/` | Configuration, prior specification, model fitting and posterior summaries |
| `scripts/` | Analysis and reporting commands |
| `outputs/` | Saved parameter summaries, aggregate descriptive data and available diagnostics |
| `PRIOR_ASSUMPTIONS.md` | Coprology prior assumptions and sensitivity analyses |

The 24 reported fits are listed in `outputs/reporting_manifest.csv`. The saved summaries can be checked without refitting:

```sh
Rscript scripts/check_reported_snapshot.R
```

Posterior draws are generated by the fitting commands and are not included in this archive. Draw-based checks and diagnostic plots require those draws.

## Interpretation

The models pool sheep and goats and assume common diagnostic accuracy within each setting. Within-herd correlation is not modelled. Latent prevalence refers to the sampled populations. The manuscript and supplement describe the sampling limitations, possible overlap between herd and slaughterhouse animals, and sensitivity to prior assumptions.
